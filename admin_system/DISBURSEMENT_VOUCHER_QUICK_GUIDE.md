## 🔑 Required Fields

### Minimum Required to Save:
- ✅ **Payee** (person/entity receiving payment)

### Recommended Fields:
- Responsibility
- City/Municipality
- Fund
- Province
- Address
- TIN
- Particulars (description)
- Amount
- All signature fields

## 💡 Tips & Best Practices

### ✅ DO:
- Fill in all fields for complete documentation
- Use full names for all signature fields
- Double-check amount calculations
- Save frequently while working
- Print after final approval
- Keep digital copies in the system

### ❌ DON'T:
- Leave payee field blank (required)
- Use abbreviations in official names
- Forget to fill in dates
- Print before getting all signatures
- Delete vouchers after submission (use status instead)

## 🖨️ Printing

1. Fill out complete voucher
2. Save to database
3. Click "Print Voucher" button
4. Review print preview
5. Adjust printer settings if needed
6. Print on A4 or Letter paper

**Print automatically:**
- Hides all buttons
- Removes colors
- Optimizes layout
- Shows only voucher content

## 💾 Database Storage

Every voucher saves:
- All form fields
- Auto-generated DV number
- User ID (who created it)
- Creation timestamp
- Update timestamp
- Status (draft/submitted/approved/completed)

## 🔍 Finding Vouchers

Click "View All Vouchers" to see:
- DV Number
- Entity Name
- Payee
- Amount
- Status badge
- Creation date

Click any voucher card to load and edit.

## ⌨️ Keyboard Shortcuts

- **Ctrl+P** / **Cmd+P** - Print voucher
- **Tab** - Move to next field
- **Shift+Tab** - Move to previous field

## 📊 Status Meanings

- 🟡 **Draft** - Work in progress
- 🔵 **Submitted** - Sent for review
- 🟢 **Approved** - Authorized for payment
- ⚫ **Completed** - Payment processed
